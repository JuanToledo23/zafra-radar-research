# official-docs

Official documents used by exercise 10 (`scripts/20_official_data.py`). The PDFs are not
versioned (see `.gitignore`); only this list is. Put the files here under the names below to
re-run the script.

**Dates.** "Published" is the date printed in the document when there is one. The weekly
reports print no publication date, so their date is the PDF creation date from the file's
metadata (`pdfinfo`), marked *(metadata)*.

**Source URLs.** For the final report, the KARBE report and the LDSCA, the URL is the
download origin recorded with the file (macOS `kMDItemWhereFroms`). The weekly reports carry
no download origin and their text names no gob.mx file URL; the only link inside them is the
CONADESUCA InfoCaña system, https://siiba.conadesuca.gob.mx/infocana/Default.aspx. Their
gob.mx attachment URLs are not recorded here. TODO (author): add them.
