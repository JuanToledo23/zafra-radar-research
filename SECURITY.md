# Security policy

This is research code with no supported deployment; the `product/` demo skeleton is meant
for local use only (its database password is a local-only default). If you find a security
problem, for example a way the download or Earth Engine code could leak credentials, please
report it privately through GitHub's "Report a vulnerability" (Security Advisories) on this
repository rather than in a public issue. Never paste credentials, `.env` contents or
tokens into issues or pull requests. Reports are acknowledged within a week; fixes go into
the next release.
