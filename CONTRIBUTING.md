# Contributing

Thanks for your interest. This is a research library maintained by one person, so issues
and small pull requests are the most useful contributions.

## Setup

```bash
make setup            # .venv with the library + download/ee/dev extras
make lint && make test
```

Python 3.11 or 3.12. On macOS, `brew install libomp` for xgboost.

## Rules

- One branch and one pull request per change. Keep it small and describe what it changes
  and how you checked it.
- `make lint` (ruff check and ruff format) and `make test` must pass. CI runs
  `pytest -m "not integration"`; the integration test needs docker.
- Results in `results/` and figures in `docs/figures/` are generated by the scripts. If a
  change alters them, regenerate them with the script and commit the script change and its
  outputs together. Never edit a generated number by hand.
- Never commit anything under `data/` (except reviewed reference polygons and labels),
  `outputs/`, credentials or `.env`.
- Numbers in the documents must match the committed results.

## Reporting a problem

Open an issue with the command you ran, the site, the full error and your platform. For
security issues see [SECURITY.md](SECURITY.md).

By contributing you agree that your code is released under the MIT licence and your data
or results under CC BY 4.0, as in the rest of the repository.
